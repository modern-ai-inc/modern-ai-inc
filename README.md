# Modern AI

Modern AI builds **Modern Discovery**.

Modern Discovery is AI recommendation intelligence software that measures how often ChatGPT, Gemini, Claude, Perplexity and Google's AI answers recommend your brand, and why.

- Product: [modernai.io/discovery](https://modernai.io/discovery)
- Public brand records: [discovery.modernai.io/categories](https://discovery.modernai.io/categories)
- Methodology: [discovery.modernai.io/methodology](https://discovery.modernai.io/methodology)
- Pricing: [modernai.io/pricing](https://modernai.io/pricing)

## Open source

- [w0-mcp-server](https://github.com/modern-ai-inc/w0-mcp-server): a free MCP server that lets any MCP-compatible AI assistant look up a brand's Recommendation Rate (how often AI picks it first) and Recommendation Inclusion Rate. Listed in the official MCP Registry.
